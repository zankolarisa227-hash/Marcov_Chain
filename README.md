## 🎯 О проекте

Исследование и production-реализация модели кредитного риска ипотечного портфеля на данных **Freddie Mac Single-Family Loan-Level Dataset**. Проект сравнивает два класса марковских моделей — **однородную цепь** и **ковариатно-зависимую спецификацию** — и дополняет их аппаратом **анализа выживаемости** для оценки времени до дефолта.

Цель — ответить на три вопроса:

1. **Куда** мигрирует заёмщик между состояниями `current → delinquent → default`?
2. **Когда** наступит терминальное событие (дефолт)?
3. **Оправдывает ли** учёт ковариат усложнение модели с точки зрения PD, ECL и регуляторных требований (МСФО 9, Базель III)?

## 🧠 Методология

### Состояния и переходы

Каждый кредит помесячно находится в одном из трёх состояний:

| Состояние | Семантика | Роль |
|---|---|---|
| **0** | платит вовремя (current) | транзиентное |
| **1** | просрочка (delinquent) | транзиентное |
| **2** | дефолт (default) | **поглощающее** |

Модель строится как цепь Маркова с дискретным временем:

$$
P(s_{t+1} = j \mid s_t = i,\; x_t) = f_i(x_t)
$$

где $x_t \in \mathbb{R}^{22}$ — вектор признаков заёмщика.

### Двойная спецификация

| Класс | Формула | Роль |
|---|---|---|
| **Однородная цепь** | $P_{ij} = n_{ij}/n_i$ | baseline |
| **Ковариатно-зависимая** | $P(x_t) = f_i(x_t)$ | main |

Внутри динамического класса реализованы **две спецификации**:

- **Параметрическая** — мультиномиальная логистическая регрессия (softmax + L2);
- **Непараметрическая** — градиентный бустинг CatBoost.

Обе обучаются **отдельно для каждого исходного состояния** — поведение из `current` и из `delinquent` описывается разными стохастическими механизмами.

### Статистический аппарат

- **Когортная оценка** матрицы $P$ с проверкой стохастичности строк;
- **Перцентильный бутстреп** (500–1000 ресэмплингов) для 95% ДИ каждой клетки;
- **LR-тест порядка марковости** с Monte-Carlo коррекцией для разреженных таблиц;
- **LR-тест временной однородности** по подпериодам;
- **Фундаментальная матрица** $N = (I - Q)^{-1}$ → Lifetime PD ($B = N R$) и среднее время до дефолта ($t = N \mathbf{1}$);
- **Forward simulation** для динамической модели — $PD(h)$ через последовательное применение $P(x_t)$, а не наивная формула $1-(1-p)^h$.

### Калибровка вероятностей

- **Platt scaling** и **изотоническая регрессия** через `CalibratedClassifierCV`;
- Калибровка выполняется **внутри train-среза** (cv=3) — без утечки на OOT;
- Метрики: **ECE**, **reliability diagram**, **calibration slope** и **intercept**.

### Out-of-Time валидация

- Train/OOT разделены **по времени** с **embargo** между ними;
- Соответствует требованиям Базеля III и МСФО 9;
- Сравнение моделей по **Brier Score**, **log-loss**, **ECE**, **калибровочному наклону**;
- Проверка значимости разницы через **тест Дибольда–Мариано** или бутстреп.

### Анализ выживаемости

Дополняет цепь Маркова непрерывной оценкой времени до дефолта:

| Инструмент | Роль |
|---|---|
| **Kaplan–Meier** | кривые $S(t)$ по группам риска |
| **Модель Кокса** | $h(t,x) = h_0(t)\exp(\beta^\top x)$, hazard ratios |
| **Остатки Шенфельда** | проверка пропорциональности рисков |
| **C-index** | дискриминационная способность |
| **Fine–Gray** | конкурирующие риски (prepayment) |

**Кросс-валидация:** кумулятивный PD $1 - S(h)$ из survival analysis сопоставляется с $(P^h)_{i2}$ из цепи Маркова — независимая проверка обеих моделей.
